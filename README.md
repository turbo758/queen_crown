Queen’s Crown Fashion Studio is a modern and stylish online fashion platform designed to showcase and sell trendy clothing and accessories. The project focuses on delivering an elegant and user-friendly shopping experience with features like product browsing, category filtering, responsive design, and smooth navigation.

This project aims to combine creativity with functionality, providing a visually appealing interface that reflects a premium fashion brand identity.

Tech Stack: HTML, CSS, JavaScript 
Purpose: College project / E-commerce website prototype
